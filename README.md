📌 About the Project

The Educational Management System is a mobile-based application designed to offer structured learning experiences for students and teachers. The system provides video courses, quizzes, and a comprehensive dashboard to manage educational content effectively.

🚀 Features

General Features

🔐 Authentication System: Secure login and registration.

🌍 Multi-language Support: Arabic & English.

🔔 Smart Notifications: Alerts for course updates, new quizzes, and system messages.

🎨 User-friendly UI: Intuitive Flutter-based interface.

🏗️ System Architecture

The system follows a three-tier architecture:

Frontend: User-friendly interfaces built with Flutter.

Backend: API-driven logic using Laravel.

Database: Efficient data handling with SQL and Eloquent.

📊 Database Design

Key Tables:

users (manages students, teachers, and admins)

courses (stores course details, pricing, and materials)

videos (links video content to courses)

quizzes (holds quiz questions and answers)

transactions (manages payments and course enrollments)

notifications (stores alerts and system messages)

and more

📌 How It Works

Students register, browse courses, and enroll.

Teachers upload educational content and manage quizzes.

Admins verify credentials and maintain the system.

Smart notifications keep users updated with course activities.

Secure transactions allow students to purchase courses safely.
